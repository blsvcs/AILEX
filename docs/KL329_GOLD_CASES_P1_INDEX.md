# AILEX KL329 Gold Cases — P1

Šis ir AILEX KL329 moduļa juridiskais kodols: atlasītas 15 lietas, kas vislabāk noder advokātiem, juristiem un pētniekiem.

## Atlases princips

- **A līmenis:** Senāta un judikatūras kodola lietas.
- **B līmenis:** praktiski nozīmīgas lietas ar aizstāvības/validācijas vērtību.
- **C līmenis:** tehnoloģiski vai pierādījumu ziņā būtiskas lietas.

## Kā izmantot

1. Sāc ar `gold_cases_master.csv`, lai filtrētu lietas pēc informācijas tipa vai kanāla.
2. Atver attiecīgo `GOLD_CASES/GCxxx_*.md` kartīti.
3. Juridiski nozīmīgus citātus pārbaudi pilnajā nolēmumā.
4. Pēc manuālas pārbaudes atzīmē precizējumus `review/gold_cases_review_queue.csv`.
