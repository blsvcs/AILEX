# AILEX KL329 Gold Findings — P2

Šī bibliotēka pārvērš KL329 judikatūru no nolēmumu saraksta par praktiski izmantojamām juridiskām atziņām.

## Rezultāts

- Izveidotas **20 kodolatziņas**.
- Katrai atziņai ir tēma, kodolatziņa, praktiskā nozīme, aizstāvības pielietojums, tipiskie pierādījumi, saistītās Gold Cases un AILEX noteikums.
- Izveidoti mašīnlasāmi dati CSV, JSON un SQLite formātā.
- Izveidota pārbaudes rinda precīzu rindkopu/lappušu atsauču pievienošanai.

## Lietošanas princips

1. Jurists sāk ar juridisko jautājumu, nevis lietas numuru.
2. AILEX atrod atbilstošo FIND kartīti.
3. Kartīte norāda saistītās Gold Cases un tipiskos pierādījumus.
4. Argumentācijai tiesā jāizmanto pilnais nolēmums un precīzas atsauces.

## Nākamais solis

P2 v2: manuāli pievienot precīzas citātu/rindkopu atsauces katrai FIND kartītei un sasaistīt tās ar Gold Cases kartītēm.
